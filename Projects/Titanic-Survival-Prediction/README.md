# Titanic Survival Prediction 🚢

A complete Machine Learning project to predict passenger survival on the Titanic using Logistic Regression.

## 📁 Project Structure

Titanic-Survival-Prediction/
├── EDA.ipynb                → Exploratory Data Analysis
├── model_training.ipynb     → Model Training & Evaluation
├── submission.csv           → Kaggle Submission File
└── README.md

## 📊 Dataset

- **Source:** [Titanic - Machine Learning from Disaster](https://www.kaggle.com/competitions/titanic)
- **Train set:** 891 rows, 12 columns
- **Test set:** 418 rows

## 🔍 EDA Highlights

- Survival distribution analysis
- Gender vs Survival comparison
- Passenger Class vs Survival
- Age distribution
- Correlation heatmap

## ⚙️ ML Pipeline

- Missing value imputation (median/mode)
- Categorical encoding (pd.get_dummies)
- Feature selection
- Train-test split (80/20)
- Logistic Regression model

## 📈 Result

| Model | Accuracy |
|---|---|
| Logistic Regression | ~80% |
