# Missing Data Handling in Pandas

This folder contains implementation and practice of different techniques used for handling missing values in datasets using Pandas and Machine Learning preprocessing concepts.

---

## Topics Covered

### 1. Missing Indicator
- Creating a new feature to indicate missing values
- Helps models understand missingness as a pattern
- Useful when missing data itself carries information

### 2. Random Sample Imputation
- Filling missing values by randomly sampling from existing values
- Maintains original data distribution
- Reduces bias compared to mean/median imputation

### 3. Handling Missing Data (Part 4)
- Advanced strategies for handling missing values
- Comparison of different imputation techniques
- Practical implementation on datasets

---

## Tools Used
- Python
- Pandas
- NumPy
- Scikit-learn

## Goal
To understand and apply different strategies for handling missing data effectively in real-world datasets, improving model performance and data quality.
